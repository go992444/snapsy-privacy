Snapsy 개인정보처리방침

시행일: 2026년 3월 22일
앱 이름: Snapsy · 패키지: com.capture.archive
운영자: 언더르트 · 문의: go992444@gmail.com

Snapsy(「앱」)는 사용자가 스마트폰에 저장한 스크린샷·이미지를 개인 보관함으로 관리하고, 기기 내 글자 인식(OCR) 등을 통해 검색·정리하는 서비스입니다. 본 방침은 Google Play를 통해 배포되는 Android 앱에 적용됩니다.

1. 수집하는 정보

앱은 다음 정보를 사용자 기기 안에서 처리·저장할 수 있습니다.

  • 사용자가 저장한 이미지 — 스크린샷, 갤러리·공유로 가져온 사진
  • OCR·검색 색인 데이터 — 이미지에서 추출한 텍스트, 사용자 메모, 태그, 카테고리
  • 앱 설정 — 자동 수집 ON/OFF, 알림·백업 관련 설정
  • 백업 파일 — 사용자가 보낸 경우, 사용자가 선택한 저장 위치에 생성

앱의 기본 동작은 운영자 서버로 사진·OCR 전체를 전송하지 않는 방식입니다. 사용자가 「공유」 등으로 다른 앱에 데이터를 보내는 경우에는 해당 앱의 정책이 적용됩니다.

2. 정보 이용 목적

  • 캡처 보관, 검색, 카테고리·폴더·캘린더 표시
  • 기기 내 OCR 및 검색 색인
  • 스크린샷 감지·분류 알림 및 백그라운드 처리 안내
  • 사용자 요청 시 백업·복원
  • 앱 안정성·기능 개선(오류 로그가 기기·개발 도구에만 남는 경우)

3. 보관 기간 및 삭제

  • 데이터는 사용자가 앱을 사용하는 동안 기기에 보관됩니다.
  • 앱 내 삭제, 앱 삭제(제거), 데이터 삭제 시 해당 기기의 앱 데이터는 삭제됩니다.
  • 사용자가 별도로 보낸 백업 파일은 사용자가 관리·삭제합니다.

4. 제3자 제공

운영자는 법령에 따른 경우를 제외하고, 사용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 사용자가 OS 「공유」 기능으로 타 앱에 콘텐츠를 전달하는 것은 사용자의 선택에 따른 것입니다.

5. 처리 위탁

앱 배포·결제·통계 등 Google Play 및 Google이 제공하는 플랫폼 서비스 이용 시, Google의 정책이 적용될 수 있습니다. 운영자가 별도 클라우드 API를 연동하는 경우 해당 기능 안내 및 방침을 앱 업데이트 시 추가할 수 있습니다.

6. 권한 안내 (Android)

기능 제공을 위해 다음 권한을 요청할 수 있습니다.

  • 사진·미디어(또는 저장소): 이미지 읽기·저장
  • 알림: 스크린샷 분류·OCR 진행 알림
  • 기타: 백그라운드 작업(글자 인식 등) — Android 버전별 표시

권한을 거부하면 일부 기능이 제한될 수 있습니다.

7. 아동

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 해당 연령의 정보를 고의로 수집하지 않습니다.

8. 방침 변경

법령·서비스 변경 시 본 페이지를 수정하며, 중요한 변경은 앱 또는 스토어를 통해 안내할 수 있습니다.
